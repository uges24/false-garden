# Third Party Notices

This branch ports and adapts technical systems from the source pack. MIT-licensed repositories are credited below. Unlicensed sources are treated as conceptual references only.

## MIT Sources Adapted

- `momentchan/false-earth`
  - Used as the direct technical base reference for large-field/grid-snapped grass, free movement, follow camera structure, terrain scale, grass performance strategy, and cosmic/world atmosphere.
- `Sujenphea/procedural-snake`
  - Used as the movement/rendering reference for procedural snake pathing, segmented body profile, dark body recolor, and cyan/violet glow behavior.
- `mattrossman/magic-marble-tutorial`
  - Used as the material reference for animated internal marble color motion, fresnel rim, and liquid/volumetric portal feel.
- `niccolofanton/codrops-singularity-demo`
  - Used as the reference for subtle floating fragments, drifting/pulling motion, and singularity-like atmosphere.
- `thebenezer/FluffyGrass`
  - Used as the reference for denser grass instancing, clump variation, blade color gradients, and gust motion.
- `Mamboleoo/SurfaceSampling`
  - Used as the reference for natural scattered object placement over terrain.

## Conceptual Only

- `cartuhok/3d-weather-codrops`
  - No license file was found during inspection, so no code or assets are copied. Sun halo/corona/flare ideas are recreated conceptually.

Full MIT license text is available in each source repository. This project does not vendor their assets.
